# ArborInversa · 逆生树

> **树型思维导图**（tree-style mind map）：内容存成一棵树 —— **竖向的是「枝」**（节点），
> **横向的是「叶」**（挂在枝上的正文），一根枝可以挂多片叶，枝上还可以带属性（键值对）。
> 交付形态是 **Windows 独立程序**：双击即用，不依赖 Node，整个文件夹可拷走。
> 仓库里只有框架 ＋ 一棵**自带的示例树**（打开就能看到框架能做什么），**不含任何个人内容**。
> 许可：**非商业**，见第九节。

---

## 一、这是什么

**ArborInversa（逆生树）** 是一个树型思维导图应用：内容存成一棵树，「枝」是节点，「叶」是挂在枝上的正文。
主交付形态是 Windows 独立程序（`ArborInversa.exe`，内置一个微型 HTTP 服务 ＋ WebView2 窗口，整个文件夹可拷走）。

### 结构

| | 方向 | 是什么 |
|---|---|---|
| **枝** | 竖向 | 树里的节点；向下可继续长枝，构成骨架 |
| **叶** | 横向 | 挂在枝上的描述板块（正文）；**一根枝可以挂多片叶**，叶名显示在枝名右侧，点击切换 |
| **属性** | — | 枝上的键值对（可选）；键与值都自由定义 |

仓库自带的那棵示例树，就是这样的形状：

```
示例树                          ← 根：整棵树的本体
├ 结构                          ← 枝：下面还能继续长枝
│   叶：枝｜叶｜属性             ← 一枝横向挂三片叶，点叶名切换
├ 能力
│   ├ 跳转                      ← 属性：类型／标签
│   └ 插图                      ← 叶里可以插图：![[图片名|题注]]
└ 用法
```

- **层级是通用的**：根 → 分支树 → 分类 → 更细的分类，想分多细就往下长几层
- **数据字段**：枝 ＝ `{name, props?, leaves, children}`；叶 ＝ `{name, desc}` —— 仅此两种
- **叶里的两种标记**：`[[枝名]]` 生成跳转；`![[图片名]]` 插图，可带题注 `![[图片名|题注]]`

### 能做什么

| 能力 | 说明 |
|---|---|
| 浏览 | 三栏工作台：目录树（左）／详情（中）／行动树（右，跳转历史）；栏宽可拖 |
| 编辑内容 | 「编辑当前枝」：改名、加改删属性、增删改叶、上传插图 |
| 改结构 | 「＋ 在当前枝下抽枝」「⇄ 迁移当前枝」「删除当前枝」 |
| 植树 | 任何一枝都能整棵转成**文本代码**，再种到别处（导出／从文件读取／复制） |
| 交给 AI 写 | 「植树 → 告诉 ai 怎么帮你写」：一键复制一段树语言说明书给任意 AI |
| 搜索 | 全文检索枝名／叶名／叶正文／属性，配**限定栏**（条件行：属性／在枝下／枝名／叶名／正文／深度／含有／排除词） |
| 属性 | 枝名上方「属性 ⁝」展开就地编辑（键值都有常用下拉）；枝名悬停 1 秒浮出只读浮层 |
| 打包发布 | 一条命令出绿色版 zip ＋ 安装包（Inno Setup） |

## 二、怎么用

### 两种形态

**① Windows 独立程序（主要形态）** —— 安装版或绿色版，双击 `ArborInversa.exe` 即可。
程序自带一个微型 HTTP 服务（自动分配空闲端口、只绑定 `127.0.0.1`、**无需管理员权限**），
再用 WebView2 窗口显示界面；唯一外部依赖是系统的 **WebView2 运行时**（Win10/11 通常随 Edge 自带，缺了会弹提示）。

**② Node 后端（开发用）** —— 在源码目录里 `node serve.js 8460`，浏览器访问 `http://<主机 IP>:8460/`。
两套后端接口完全一致：GET `/`、GET `/data`、POST `/save`、POST `/upload`、GET `/media/<文件名>`。

### 第一次打开：自带一棵示例树

打开就是一棵「示例树」（根就叫「示例树」）—— 它演示这套框架能做什么：一枝多叶、属性、跳转、插图、更深的层级。
随便改、随便删。

- **重置成出厂样子**：「植树」→「从文件读取」→ 选随包的《示例树.txt》→「植树」（与当前枝同名会就地覆盖）
- **看一份完整内容实例**：同样地导随包的《美术史树-试用.txt》（一份 121 枝／141 叶的美术史树）
- **清空某根枝**：选中它，点「删除当前枝」

### 界面速览

| 位置 | 是什么 |
|---|---|
| 左栏 | **目录树**：点枝切换；多叶的枝，枝名右侧显示叶名小标签 |
| 中栏 | **详情**：枝名 ＋ 叶标签（点叶名切换正文）；枝名上方是「属性 ⁝」按钮 |
| 右栏 | **行动树 ⇄ 搜索**：两个小标签切换。「行动树」是跳转历史；「搜索」见第一节的能力表 |

工具栏六个按钮：`编辑当前枝`｜`＋ 在当前枝下抽枝`｜`植树`｜`⇄ 迁移当前枝`｜`删除当前枝`｜`⌂ 根`。
搜索框快捷键是 **Ctrl+K**。

## 三、树的文本代码

任何一枝（连同它下面的所有枝与叶）本身就是一棵完整的树，可以整棵转成**文本代码**，再种到别处。
四种语句，写法与内容无关：

| 写法 | 含义 |
|---|---|
| `树 名称` | **整棵树的标题**，只认最上面一行，其下语句即正文 |
| `枝 名称` | 一根枝；从它开始就是一棵子树 |
| `叶 名称` | 一片叶；**它的内容 ＝ 紧跟其后、缩进比它更深的所有行** |
| `属性 键: 值` | **该枝（或该树）的属性**，写在所属枝行下方、与「叶」行同级；值用逗号分隔即为多个 |

真实的一段（就是仓库里那棵示例树的开头）：

```text
树 示例树

  枝 示例树
    属性 类型: 示例
    属性 标签: 框架演示, 入门

    叶 概述
      这是一棵演示框架的示例树：结构、叶、属性、跳转、插图都在里面。
      想看真实内容实例，就导随包的《美术史树-试用.txt》。

    枝 结构
      属性 类型: 分类

      叶 枝
        竖向的是枝，也就是树的节点。枝往下还能继续长枝，构成整棵树的骨架。
```

- **缩进**：空格 1 列、Tab 4 列、全角空格 2 列（列 ≠ 字符数）；比「叶」行更深的缩进**一律算叶的内容**，
  所以正文里出现「枝 X」这样的行不会被误当结构
- **排版**：分段用空行；引号统一用 `『』`；提到已有的枝名写成 `[[枝名]]`，点一下就跳过去
- 出错会报行号：`代码有误 —— 第 3 行：只能以「树 名称」「枝 名称」「叶 名称」开头…`
- 「植树」弹窗里：`生成当前枝的代码`／`从文件读取`／`复制`／`清空`／`植树`，
  另有 **语法** 与 **告诉 ai 怎么帮你写**（点开、一键复制给任意 AI，它就能替你写合规代码）

## 四、数据模型

一棵树就是一个 JSON：

```json
{
  "name": "示例树",
  "props": { "类型": "示例", "标签": ["框架演示", "入门"] },
  "leaves": [ { "name": "概述", "desc": "…（这一片叶的正文）" } ],
  "children": [
    {
      "name": "结构",
      "leaves": [
        { "name": "枝", "desc": "…" },
        { "name": "叶", "desc": "…" }
      ],
      "children": [ … ]
    }
  ]
}
```

- **枝**：`name`（枝名）、`props`（属性，可选）、`leaves`（叶数组）、`children`（下枝数组）
- **叶**：`name`（叶名）、`desc`（叶的内容）—— 仅此两种
- **属性值**：只能是文本或文本数组；多值写成数组，**不要写单元素数组**
  （`{"键": "文本"}` 或 `{"键": ["值一", "值二"]}`）
- 根的直接下枝相当于「一棵分支树」（一个学科／一个主题一棵，可以平行挂多棵），再往下按需要分层

## 五、目录结构

| `media/` | 图片目录（仓库里只有示例树要用的那张演示插图） |
| `tools/` | `check_data.js`（内容自检）、`tree.test.js`／`codec.test.js`／`search.test.js`（三套自测）、`codec-from-html.js`、`make_trial_code.js`、`seed_props.js`、`pngtool.py`（图标）、`build_release.py`（打包）、`git-hooks/pre-commit` |
| `win-app/` | Windows 应用源码 `Program.cs`、程序图标、安装包脚本 `setup.iss`、外发版《使用说明》 |
| `LICENSE.md` | 许可全文 |

程序目录（绿色版解压后／安装版装好后）：

| 文件 | 作用 |
|---|---|
| `ArborInversa.exe` | **主程序**（x86，已内嵌图标） |
| `index.html` | 界面页面（改完重启程序生效） |
| `data.json` | **你的全部内容**（应用内编辑会写回这个文件） |
| `media/` | 插图目录（编辑器里上传的图都进这里） |
| `示例树.txt`／`美术史树-试用.txt` | 随包的示例树、完整内容实例的试用代码（随时可重新导入） |
| `使用说明.txt`／`LICENSE.md` | 给使用者的说明、许可全文 |
| `WebView2Loader.dll` 等三个 DLL | WebView2 依赖（32 位，必需） |
| `ArborInversa.exe.WebView2/` | 运行缓存，首次运行自动生成，可随时删 |

## 六、自己编译与打包

**重新编译主程序**（在 Windows 侧执行，需要 .NET Framework 自带的 `csc.exe`）：

```bat
cd <程序目录>
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /platform:x86 /codepage:65001 ^
  /out:ArborInversa.exe /win32icon:ArborInversa.ico ^
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll ^
  /reference:Microsoft.Web.WebView2.Core.dll /reference:Microsoft.Web.WebView2.WinForms.dll ^
  Program.cs
```

> 注意：**必须带 `/platform:x86`**：WebView2 依赖的 DLL 是 32 位的，用默认的 AnyCPU 在 64 位系统上会因架构不匹配
> 而初始化失败（现象是窗口出来了但内容一片空白，且不报错）。

**打外发版**（绿色版 zip ＋ 安装包，产物落 `dist/`）：

```bash
python3 tools/build_release.py
```

包内 13 个文件：主程序、`.exe.config`、`index.html`、`data.json`（示例树）、`media/`、`使用说明.txt`、
`示例树.txt`、`美术史树-试用.txt`、`LICENSE.md`、三个 WebView2 DLL。
安装包由 Inno Setup 6 编译（脚本 `win-app/setup.iss`），装到 `%LOCALAPPDATA%\ArborInversa`（免管理员）；
`data.json` 与 `media/` 标为「已存在就不覆盖、卸载也不删」—— **升级不丢内容、卸载不删内容**。

## 八、开发约定

1. **界面文案**：「枝」就叫枝，「叶」就叫叶；两者并列时写「**枝、叶**」——**不用「枝叶」这种合成词**。
   一律不用 emoji（纯排版符号可用 `＋ ⇄ ⌂ ▼ ● ○ → ⁝`）。
2. 改了 `index.html` 里的**编解码**或**搜索**之后，跑一遍 `node tools/tree.test.js`。
