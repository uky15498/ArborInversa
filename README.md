# ArborInversa · 逆生树

**树型思维导图**：内容存成一棵树 —— **竖向的是「枝」**（节点），**横向的是「叶」**（挂在枝上的正文），
一枝可以多叶，也能标属性（键值对）。

> ### 下载
> **安装程序（推荐）** 或 **绿色版**，都在 [Releases](https://github.com/uky15498/ArborInversa/releases/latest) 里。
> 安装后，生成的整个文件夹可以打包带走。
> 打开自带示例。

## 一、怎么安装

### 在线试用（不用安装）

[**点此在线试用便携版**](https://uky15498.github.io/ArborInversa/) —— 打开就是那棵示例树，
手机、平板、别人的电脑都能开，不用装任何东西。

- 随便点、随便改；**改完能一键复制成树语言文本，或另存为一份 HTML** 带走
- **改动只留在你自己的浏览器里**：别人看不到，也碰不到服务器上的任何东西 ——
  这一页是静态文件，它只会被读下来，没有任何接收写入的接口。标题栏会一直提醒「有改动未导出」
- 它是**一个自包含的 HTML**：内容就写在文件自己身上，整份另存下来，离线双击也能接着用

### 安装程序（推荐）

1. 打开 [Releases](https://github.com/uky15498/ArborInversa/releases/latest)，下载 `ArborInversa-Setup-*.exe`
2. 双击安装
3. 首次运行若被 Windows 拦下（「Windows 已保护你的电脑」）→ 点「更多信息」→「仍要运行」

**升级不会覆盖你的内容，卸载也不会删你的内容。**

### 绿色版

1. 下载 `ArborInversa-*.zip`，解压到任意文件夹
2. 双击 `ArborInversa.exe` —— 整个文件夹可以拷到别的电脑直接用

唯一的外部依赖是系统的 **WebView2 运行时**：Win10／11 一般随 Edge 自带；缺了程序会提示。

## 二、怎么用

### 第一次打开：自带示例树

示例树用于展示结构，删改不影响使用。

- **初始化**：「植树」→「从文件读取」→ 选随包的 `示例树.txt` →「植树」（与当前枝同名会就地覆盖）
- **查看实例**：同样地导随包的《美术史树-试用.txt》（一棵半成品的美术史树，用来对照真实内容的写法）
- **清空某根枝**：选中它 →「删除当前枝」

### 界面

| 位置 | 是什么 |
|---|---|
| 左栏 | **目录树**：点枝切换；多叶的枝，枝名右侧显示叶名小标签 |
| 中栏 | **详情**：枝名 ＋ 叶标签（点叶名切换正文）；枝名上方是「属性 ⁝」按钮 |
| 右栏 | **行动树 ⇄ 搜索**：两个小标签切换。「行动树」是跳转历史，「搜索」见下 |

工具条：`↶ 撤销`｜`编辑当前枝`｜`＋ 在当前枝下抽枝`｜`植树`｜`⇄ 迁移当前枝`｜`删除当前枝`｜
`⌂ 根`｜`云`（手机版顶栏分两行：第一行品牌名，第二行就是这条按钮带，可左右滑）。

- **撤销**：任何一次改动（改名／展叶／抽枝／删除／迁移／植树／改属性）都能撤回，
  也可以按 **Ctrl+Z**（在输入框里按则是撤销打字）。鼠标停在「↶ 撤销」上会写清要撤销的是哪一步
- **行动树那一行左边的 `◁ ▷`**：回到上一个／下一个走过的枝，跟浏览器前进后退一个意思

- **搜索**：右栏切到「搜索」，按 **Ctrl+K** 也能直接进。除了关键词，还有**限定栏** ——
  点「＋ 条件」按维度加条件（属性／在枝下／枝名／叶名／正文／深度／含有／排除词），
  多条之间可以「并且」「或者」，**不用背语法**
- **属性**：枝名上方「属性 ⁝」展开就地编辑（键与值都有常用下拉，也可以直接填）；
  鼠标在枝名上停 1 秒，会浮出只读浮层
- **植树**：把任何一枝整棵导出／导入成文本代码（见第四节）；弹窗里还有
  **「告诉 ai 怎么帮你写」**，一键复制一段说明书给任意 AI，它就能替你写出合规代码
- **改动**（植树弹窗下半截）：先「生成当前枝的代码」拿到**原文**，丢给 AI 让它放手改，
  再把改好的**全文**粘回来点「比对」—— 程序自己算差在哪，逐条列出来，勾选的才落地。
  这条路的要点：让 AI 交全文，不要让它算「删哪几行、加哪几行」

## 三、云端：在服务器上存自己的树（可选）

默认内容存在本机（安装版在 `data.json`，便携版在 HTML 自己身上）。**如果自己有服务器**，
可以再开一份云端：任何设备打开网页、登录自己的账号，读写的是同一棵树。

```
账号 = 用户名 + 口令 + 分区
分区 = 广韵十六摄（通江止遇蟹臻山效果假宕梗曾流深咸）
       用户名是自定义的、会撞名；16 个区就是 16 个格 ——
       同名的第 1 个人进「通」，第 2 个进「江」……最多并存 16 个，互不干扰
```

分区平时**不显示**：登录只要输用户名和口令（口令对上哪个区就是哪个），
想知道自己在哪个区，点开顶栏的「云」看「用户数据」，或把鼠标停在用户名上。

自己搭（一台装有 Node 的服务器，零依赖、不用数据库）：

```bash
node tools/build_cloud_bundle.js          # 打出 dist-cloud/arborinversa-cloud.tar.gz
# 把压缩包丢到服务器上解开，然后：
sudo sh 安装.sh 8488                      # 装好服务（systemd，开机自启）
# 安全组放行 8488，浏览器打开 http://<服务器IP>:8488/ 就是应用
```

★ 用**非标端口 ＋ IP** 访问，就不涉及域名备案；网页和接口都由这一个服务发出，
所以**不需要域名、也不需要 HTTPS 证书**（介意明文传输的话可以给它自签证书，
或用 nginx 反代终止 TLS——细节见 `tools/cloud-部署.md`）。

存树带版本号：同一棵树在别的设备改过，保存时会问「用我的覆盖」还是「取云端的」，不会默默盖掉。

## 四、自己写内容：树的文本代码

任何一枝（连同它下面的枝与叶）本身就是一棵完整的树，可以整棵转成文本代码，再种到别处。

| 写法 | 含义 |
|---|---|
| `树 名称` | 整棵树的标题，只认最上面一行 |
| `甲子 枝 名称` | 一根枝；前面的**干支就是层级**（甲子＝第 1 层、乙丑＝第 2 层…癸亥＝第 60 层） |
| `乙丑 叶 名称` | 一片叶；**它的正文 ＝ 紧跟其后、不写干支的那些行** |
| `乙丑 属性 键: 值` | 这根枝的属性；值用逗号分隔即为多个 |

**层级用六十甲子**：按原序，不循环。这样写的好处是不用数空格 ——
八层深的地方原来每行要 16 个空格，现在只要两个字的干支，AI 也不会多打一个空格就串层。
写 **阿拉伯数字**（`3 枝 浙派`）、**中文数字**（`三 枝`）、**破折号**（`－－ 枝`）都认，
甚至老的空格缩进格式也照旧能导；但导出统一成干支。

一段真实的（就是自带示例树的开头）：

```text
树 示例树
枝 示例树
甲子 属性 类型: 示例
甲子 属性 标签: 框架演示, 入门
甲子 叶 概述
  这是一棵演示框架的示例树，随便改、随便删。

甲子 枝 结构
乙丑 叶 枝
  竖向的是枝，也就是树的节点，往下还能继续长枝。
```

- **正文**：跟在「叶」后面、不写干支的行就是那片叶的内容；正文里出现「枝 X」这种字样不会被误当结构
  （真要顶格写「甲子 枝 某某」，行首加个 `/` 转义）
- **老格式仍能导入**：2 空格缩进那一套、破折号那一套、纯数字那一套，程序自己认
- **排版**：分段用空行；引号统一用 `『』`；提到已有的枝名写成 `[[枝名]]`，点一下就跳过去；
  插图写 `![[图片名|题注]]`
- 写错了会报行号：`代码有误 —— 第 3 行：只能以「树 名称」「枝 名称」「叶 名称」开头…`

### 改一棵树时：让 AI 改，让程序算差

整棵树导出再种回去太重，手写「删这一行、加那一行」又会随篇幅与结构变化而失效。所以默认这样用
（「植入」和「改动」是弹窗里的两页，各占一屏，手机上也不挤）：

1. 「植树」→ 切到「**改动**」这一页 →在「改哪一根」里挑要动的那根（默认就是当前枝自己，
   不把它下面的枝一起带进来；旁边标着这一根大约多少字，挑之前心里有数）
2. 点「取这份原文」，或在「连同要求一起复制给 AI」里写上你的要求，一次复制到位
3. 让 AI **直接给全文**（不要给片段、也不要写「第几行删掉」）
4. 把 AI 交回来的全文粘到「②」→「比对」→ 逐条列出**加枝／删枝／加叶／删叶／改正文／改属性**
5. 勾掉不想收的，点「落地」；一次落地是一步撤销

| 改了什么 | 程序怎么认 |
|---|---|
| 叶的正文 | 按**叶名**对上，正文按行比，差几行说几行 |
| 加／删 一片叶、一根枝 | 名字对不上就是加，原文有、改文没有就是删 |
| 枝的顺序变了 | 不算改动（按名字对齐，不认位置） |
| 同一根枝下有两片同名的叶 | 会提示「指不准」，此时不动手，让你先说清 |

上面这套只处理「改过的全文」。要**精确定点小修**（只写一句改动、不贴全文），弹窗里还有一套编辑语言：

```text
进入 明/绘画/山水/浙派/戴进     ← 进入这根枝（路径从当前枝数起）
属性 别名: 文进                ← 加/改属性；值写减号＝删掉属性
叶 变迁                        ← 这片叶有了就换正文，没有就新建
  浙派……
删叶 形势                      ← 抽掉一片叶（「删」则删掉点名的整根枝）
株 明/绘画                     ← 「这一根就是这样」：整根覆盖，块里没写的叶会被删掉
  枝 绘画
    叶 概述
      新的正文
```

`株` 与普通 `枝` 的区别就是**要不要删**：普通写法只做加法（没写的部分原样留着），
`株` 说的才是「整根换成这个样子」。所以想让 AI 删东西，要么让它交全文走上面的比对，要么用 `株`。

## 五、内容存在哪 / 数据是什么样

树就是一个 JSON 文件：`data.json`（在程序目录里）。

```json
{
  "name": "示例树",
  "props": { "类型": "示例", "标签": ["框架演示", "入门"] },
  "leaves": [ { "name": "概述", "desc": "…（这一片叶的正文）" } ],
  "children": [ { "name": "结构", "leaves": [ … ], "children": [ … ] } ]
}
```

- **枝**：`name`（枝名）、`props`（属性，可选）、`leaves`（叶）、`children`（下枝）
- **叶**：`name`（叶名）、`desc`（叶的正文）
- **属性值**：只能是文本，或文本数组；多值写数组，**不要写只有一个元素的数组**
- **图片**放在同目录的 `media/` 里（编辑器里上传的图也进那里）
- 根的直接下枝相当于「一棵分支树」：一个学科／一个主题一棵，可以平行挂几棵
- **改之前先备份这个文件**；想整体换内容，用「植树」把树导进导出最省事

## 七、给想改代码的人

仓库里三个文件就能跑起来：`index.html`（界面，含全部 CSS／JS，无外部依赖）、`data.json`（自带示例树）、
`serve.js`（备用 Node 后端）。其余：

| 文件 | 作用 |
|---|---|
| `示例树.txt` | 示例树的文本代码形式（唯一来源）；改完跑 `node tools/check_data.js --write` 重新生成 `data.json` |
| `media/` | 图片目录（仓库里有示例树的五张演示插图） |
| `tools/` | 五套自测、内容自检、属性播种、发布脚本等 |
| `win-app/` | Windows 程序源码 `Program.cs`、程序图标、安装包脚本 |
| `LICENSE.md` | 许可全文 |

自测（都**从 `index.html` 里抽取真实实现**来跑，不依赖浏览器）：

```bash
node tools/tree.test.js     # 37 项：夹具就是仓库自带的示例树，谁 clone 下来都能跑
node tools/codec.test.js    # 28 项：树 ⇄ 文本代码（需要一份内容数据，没有会提示跳过）
node tools/search.test.js   # 45 项：搜索 与 枝属性（同上）
node tools/cloud.test.js    # 30 项：云端登录的分区/口令提示（不联网，fetch 由假服务器接管）
node tools/edit.test.js     # 24 项：改动（差异／勾选／落地）与编辑语言，纯函数夹具
```

两条约定：

1. **界面文案**：「枝」就叫枝，「叶」就叫叶；两者并列时写「**枝、叶**」，不用「枝叶」这种合成词；一律不用 emoji
2. 改了 `index.html` 里的**编解码**或**搜索**之后，跑一遍 `node tools/tree.test.js`
